# Fiji Macro Workshop

This repository contains materials for a workshop on writing macros in
[Fiji](https://fiji.sc/), the ImageJ distribution commonly used for image
analysis workflows.

## Workshop goals

By the end of the workshop, participants should be able to:

- open and run a macro in Fiji
- record actions to generate macro code
- edit recorded macros to automate repetitive image-processing tasks
- save and reuse macros in their own analysis workflows

## Requirements

To follow along, install Fiji before the workshop:

1. Download Fiji from <https://fiji.sc/>
2. Launch Fiji and confirm it opens correctly
3. Open the macro editor from `Plugins -> New -> Macro`

## Working with macros in Fiji

Common ways to start writing a macro:

- use `Plugins -> Macros -> Record...` to record actions as code
- paste macro code into the macro editor
- run macros from the editor with the `Run` button

## Repository purpose

This repository serves as the home for workshop notes, examples, and exercises
related to writing Fiji macros.
